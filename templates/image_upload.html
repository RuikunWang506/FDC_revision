Catalog Images / 目录图片: Main product images with white background, specs, dimensions. Supports versioning (T9998.jpg, T9998_v2.jpg, etc.) / 主产品图片，白色背景、规格、尺寸。支持版本控制
Detail Images / 细节图片: Organized by style folders. Each folder name = SKU, images inside belong to that style. Duplicate filenames get auto-suffix (_01, _02, etc.) / 按款式文件夹组织。文件夹名=款号，里面的图片属于该款式。重复文件名自动添加后缀
Supported Formats / 支持格式: JPG, PNG, BMP, TIFF, WEBP + ZIP/RAR archives / 图片格式及ZIP/RAR压缩包
Upload Methods / 上传方式: Drag & drop, select multiple files, select folders, or upload archives / 拖放、选择多个文件、选择文件夹或上传压缩包
Upload Time / 上传时间: ~1-2 seconds per MB (167MB ≈ 3-5 minutes). Archives take longer due to extraction. / 每MB约1-2秒（167MB约3-5分钟）。压缩包因解压需更长时间。
