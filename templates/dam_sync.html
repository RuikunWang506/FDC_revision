How It Works
How unattended sync actually works

Nothing runs “by magic” in the browser. One of these must be configured on the Windows server:

  1. Task Scheduler runs auto_run/daily_auto_sync.bat once per day, which calls POST …/dam/cron/start with header X-DAM-Cron-Secret matching env DAM_CRON_SECRET on the machine running Flask.
  2. Or run python py/standalone/smart_auto_filter.py on a schedule (copies from Dropbox per Config paths), then run DAM sync separately.

Check server logs and C:\FDC_FLASK_APP\daily_sync.log after the scheduled time. GET …/dam/cron/status (same secret header) returns is_running / last_run for scripts.

Green button only runs when you click it (or when Task Scheduler hits the cron URL). Set DAM_CRON_SECRET on the server, then point the batch file at your real base URL (DAM_SYNC_BASE_URL).
When to Use Manual Sync
  • Green "Auto Sync" button:
    • Click after uploading many files (don't wait for the daily sync)
    • Or let the Windows scheduled task run once every 24 hours
  • Yellow "Complete Rebuild" button:
    • Only if having database issues
    • Or after major file reorganization
If nothing is scheduled on the server, use the green button after large Dropbox uploads.
