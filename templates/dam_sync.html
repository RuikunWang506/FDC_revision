About DAM Sync V2
Features:
  • Batch Processing: Commits data every 100 records to prevent rollback on failure
  • Progress Tracking: Real-time progress updates every 100 files
  • Index Files: Pre-scans directories and creates index files for faster processing
  • Scheduled Sync: Automatically runs every 3 days when triggered
  • Error Recovery: Continues processing even if individual files fail
Index Files:
  • D:\Individual_big_picture\index.json - Big picture images index
  • D:\Catalog_pictures\catalog_original\index.json - Catalog images index
Scheduled Task Setup:

To set up automated sync every 3 days:

  1. Open Windows Task Scheduler
  2. Create New Task
  3. Trigger: Every 3 days at 2:00 AM
  4. Action: Run C:\FDC_FLASK_APP\run_scheduled_dam_sync.bat
