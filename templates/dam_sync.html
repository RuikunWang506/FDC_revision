How It Works
Fully Automated

The system runs automatically every hour (Mon-Fri 9am-5pm):

  1. Checks Dropbox for new/changed/deleted folders
  2. Copies new images to server
  3. Updates database with new files
  4. Removes broken links from deleted files
You don't need to do anything! The green button runs automatically.
When to Use Manual Sync
  • Green "Auto Sync" button:
    • Click after uploading many files (don't wait for hourly sync)
    • Or just let it run automatically
  • Yellow "Complete Rebuild" button:
    • Only if having database issues
    • Or after major file reorganization
Most users never need to click anything!
