    Overview

    Container Hub lists every container from the Google tracking sheet. Use it to import new containers into OMS, manage ocean POs, receive at 827, and download related files.

    Status colors
    New Dropbox file ready, not yet in OMS
    Ocean PO created in OMS, not fully received
    Landed Received at 827 (RCVD_QTY > 0)
    Waiting On sheet but no Dropbox source file
    Columns
    • Container — click to open item lookup. FT… numbers display as F….
    • BOL — bill of lading from the sheet.
    • Written Time — when the row was written on the Google sheet.
    • PO Created — OMS PO date/time from FDC (pur_ord + plog). Blank if no PO exists yet.
    Filters, search & pages
    • Click the pills (All / New / Ocean / Landed / Australia (L)) to filter the list.
    • Use the search box to find a container # or BOL.
    • The table shows 25 rows per page; use pagination at the bottom.
    • Refresh reloads sheet + OMS data (bypasses cache).
    Actions by status
    • New → Process — reads the Dropbox container file, opens the style preview grid, then imports styles (FDC + EFAS) and PO (FDC only) after you confirm.
    • New → Files — download the original source file only.
    • Ocean → PackingList / Receive — opens the packing list in a new tab, then asks whether the container arrived at 827. Answer Yes to receive into OMS and update the sheet RCD column.
    • Ocean / Landed → Files — download PO CSV, Styles CSV, or Original.
    • Ocean / Landed → Edit — Delete PO removes OMS records; Reprocess re-runs import preview; Un-landed (landed only) reverses 827 receive and moves back to ocean.
    Import preview tips
    • Yellow rows = color names auto-converted to abbreviations — review before confirming.
    • You can edit Style, Color, Item#, Cost, Retail, and PO Qty in the grid.
    • Click Confirm Import only after the data looks correct.
    Header shortcuts
    • Manual Process Container — alternate import path at /container.
    • Google Sheet — open the live tracking spreadsheet.
    页面说明

    Container Hub 显示 Google 跟踪表中的所有货柜。用于将新货柜导入 OMS、管理在途 PO、827 收货，以及下载相关文件。

    状态颜色
    New 新建 Dropbox 有源文件，尚未导入 OMS
    Ocean 在途 OMS 已建 PO，尚未完全收货
    Landed 已到 已在 827 收货（RCVD_QTY > 0）
    Waiting 等待 表中有记录，但 Dropbox 无源文件
    列说明
    • Container 货柜号 — 点击可打开货品查询。FT… 会显示为 F…。
    • BOL 提单号 — 来自 Google 表。
    • Written Time 写入时间 — Google 表上该行的写入时间。
    • PO Created 建 PO 时间 — FDC OMS 中 PO 的日期/时间（pur_ord + plog）。尚未建 PO 时显示空白。
    筛选、搜索与分页
    • 点击上方标签（All / New / Ocean / Landed / Australia (L)）筛选列表。
    • 搜索框可按货柜号或 BOL 查找。
    • 表格每页显示 25 条，底部可翻页。
    • Refresh 刷新 重新加载表格与 OMS 数据（跳过缓存）。
    各状态操作
    • New → Process 处理 — 读取 Dropbox 货柜文件，打开款式预览表，确认后导入款式（FDC + EFAS）和 PO（仅 FDC）。
    • New → Files 文件 — 仅下载原始源文件。
    • Ocean → PackingList / Receive 装箱单/收货 — 新窗口打开装箱单，然后询问是否已在 827 到货。选 Yes 将在 OMS 收货并更新 Google 表 RCD 列。
    • Ocean / Landed → Files 文件 — 下载 PO CSV、Styles CSV 或 Original 原文件。
    • Ocean / Landed → Edit 编辑 — Delete PO 删除 PO 清除 OMS 记录；Reprocess 重新处理 重新打开导入预览；Un-landed 取消到货（仅 Landed）撤销 827 收货并回到在途状态。
    导入预览提示
    • 黄色行 = 颜色名称已自动转换为缩写，确认前请核对。
    • 可在表格中修改 Style、Color、Item#、Cost、Retail、PO Qty。
    • 数据无误后再点击 Confirm Import 确认导入。
    顶部快捷入口
    • Manual Process Container 手动处理 — 备用导入页面 /container。
    • Google Sheet 谷歌表格 — 打开实时跟踪表。
