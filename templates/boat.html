    {{ te('Overview') }}

    Container Hub lists every container from the Google tracking sheet. Use it to import new containers into OMS, manage ocean POs, receive at 827, and download related files.

    {{ te('Status colors') }}
    {{ te('New') }} Dropbox file ready, not yet in OMS
    {{ te('Ocean') }} PO created in OMS, not fully received
    {{ te('Landed') }} Received at 827 ({{ te('RCVD_QTY') }} > 0)
    {{ te('Waiting') }} On sheet but no Dropbox source file
    {{ te('Columns') }}
    • {{ te('Container') }} — click to open item lookup. {{ te('FT…') }} numbers display as F….
    • {{ te('BOL') }} — bill of lading from weekly tracking; vessel name shown below.
    • {{ te('ETD / ETA') }} — departure (ETD) on top, arrival (ETA) below from weekly tracking.
    • Received 收货 — RCD date from the Google sheet (when received at 827).
    • {{ te('Written Time') }} — when the row was written on the Google sheet.
    • {{ te('PO Created') }} — OMS PO date/time from FDC ({{ te('pur_ord') }} + {{ te('plog') }}{{ te('). Blank if no PO exists yet.') }}
    • Receive Time 收货时间 — when the PO was received into OMS. Packing-slip / mark-landed activity log (clock time) first; if missing, OMS inv_data.LASTRCV_DT date only. Landed rows sort newest first by this column.

    • {{ te('New → Files') }} — download the original source file or Packing List.
    • {{ te('Ocean → PackingList / Receive') }} — opens the packing list in a new tab, then asks whether the container arrived at 827. Answer {{ te('Yes') }} to receive into OMS and update the sheet RCD column.
    • {{ te('Ocean / Landed → Files') }} — download PO CSV, Styles CSV, Original, or Packing List.
    • {{ te('Ocean / Landed → Edit') }} — {{ te('Delete PO') }} removes OMS records; {{ te('Reprocess') }} re-runs import preview; {{ te('Un-landed') }} (landed only) reverses 827 receive and moves back to ocean.
    • {{ te('MSRP column') }} — Excel only: {{ te('OK') }} (all Price1 filled) or {{ te('Need Ken') }} (any Price1 missing).
    • {{ te('Ocean / Landed → Update MSRP') }} — next to Edit when Excel MSRP is OK and any PO SKU in OMS still has $0 retail; pushes Price1 to FDC + EFAS.

    页面说明

    Container Hub 显示 Google 跟踪表中的所有货柜。用于将新货柜导入 OMS、管理在途 PO、827 收货，以及下载相关文件。

    状态颜色
    New 新建 Dropbox 有源文件，尚未导入 OMS
    Ocean 在途 OMS 已建 PO，尚未完全收货
    Landed 已到 已在 827 收货（{{ te('RCVD_QTY') }} > 0）
    Waiting 等待 表中有记录，但 Dropbox 无源文件
    列说明
    • Container 货柜号 — 点击可打开货品查询。{{ te('FT…') }} 会显示为 F…。
    • BOL 提单号 — 来自每周跟踪表；下方显示船名。
    • {{ te('ETD / ETA') }} — 上方为离港 ETD，下方为到港 ETA。
    • Received 收货 — Google 表 RCD 收货日期（827 到货）。
    • Written Time 写入时间 — Google 表上该行的写入时间。
    • PO Created 建 PO 时间 — FDC OMS 中 PO 的日期/时间（{{ te('pur_ord') }} + {{ te('plog') }}）。尚未建 PO 时显示空白。
    • Receive Time 收货时间 — OMS 收货时间：优先装箱单下载 / 标记已到货日志（含时钟）；没有日志时用 inv_data.LASTRCV_DT 日期。Landed 列表按此列从新到旧排序。
    筛选、搜索与分页
    • 点击上方标签（{{ te('All / New / Ocean / Landed / Australia (L)') }}）筛选列表。
    • 搜索框可按货柜号或 BOL 查找。
    • 表格每页显示 25 条，底部可翻页。
    • Refresh 刷新 重新加载表格与 OMS 数据（跳过缓存）。
    各状态操作
    • New → Process 处理 — 读取 Dropbox 货柜文件，打开款式预览表，确认后导入款式（FDC + EFAS）和 PO（仅 FDC）。
    • New → Files 文件 — 下载原始源文件或装箱单。
    • Ocean → PackingList / Receive 装箱单/收货 — 新窗口打开装箱单，然后询问是否已在 827 到货。选 {{ te('Yes') }} 将在 OMS 收货并更新 Google 表 RCD 列。
    • {{ te('Ocean / Landed → Files 文件') }} — 下载 PO CSV、Styles CSV、Original 原文件或装箱单。
    • {{ te('Ocean / Landed → Edit 编辑') }} — Delete PO 删除 PO 清除 OMS 记录；Reprocess 重新处理 重新打开导入预览；Un-landed 取消到货（仅 Landed）撤销 827 收货并回到在途状态。
    • MSRP 列 — 仅看 Excel：{{ te('OK') }}（Price1 齐全）或 {{ te('Need Ken') }}（Price1 有缺失）。
    • Update MSRP 更新零售价 — 在 Edit 旁，Excel 为 OK 且该 PO 仍有 SKU 在 OMS 零售价为 $0 时显示；从 Excel Price1 写入 FDC + EFAS。
    导入预览提示
    • 黄色行 = 颜色名称已自动转换为缩写，确认前请核对。
    • 可在表格中修改 Style、Color、Item#、Cost、Retail、PO Qty。
    • 数据无误后再点击 Confirm Import 确认导入。确认供应商后弹窗立即关闭，右上角提示结果，该行单独更新，可继续处理下一个货柜。
    顶部快捷入口
    • Manual Process Container 手动处理 — 备用导入页面 {{ te('/container') }}。
    • Google Sheet 谷歌表格 — 打开实时跟踪表。
